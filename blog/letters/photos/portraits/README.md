# fanfan 的美照

每个子文件夹对应一组相片。把新的 JPG、PNG、WebP、GIF 或 AVIF 放进同组文件夹，Pages 发布后会自动把它们放在一起展示。网页会沿用该组的翻片效果。手机拍摄的 HEIC 可以先导出成 JPG。

想给某张照片写一句话时，在 `../../entries.js` 的 `portraits` 中添加一条记录，`file` 填「子文件夹/文件名.jpg」并填写 `caption`。在电脑上整理完新照片后，双击工作区中的「打开本地博客」即可按当前目录预览。直接双击 HTML 时会使用随站点保存的离线照片清单。

这份相册随公开仓库一起发布，请只放双方愿意公开的照片。
