# 我与 fanfan 的幸福日常

从《见字如面》的「生活记录」翻开年册。每个年份里都可以收美食和约会。

- **美食**　放在 `美食/YYYY-MM/`，例如 `美食/2026-11/`。照片可以保留原文件名，网页会将这个文件夹里的照片放进同一个月的照片墙。
- **约会**　放在 `约会/`，按「YYYY-MM-DD-照片标题.jpg」命名。同一天的照片会排在一起。也可以为一次出游建立 `约会/2027-01-01-散步/`，里面的照片会继承文件夹日期。
- **写批注**　在 [entries.js](../../entries.js) 的 `outings` 里写整次约会的标题和 `caption`。同一文件的 `days` 里有每张约会照片各自的 `caption`，可以单独填写或留空。纯文字手记只需在 `days` 添加 `date` 和 `caption`。

Pages 发布时会扫描子文件夹。双击工作区的「打开本地博客」也可以预览新照片。直接打开 HTML 使用随网页保存的离线清单。

这里的照片、文字随公开仓库一起发布，请只放双方愿意公开的内容。
